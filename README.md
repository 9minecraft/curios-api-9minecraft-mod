# Curios API — Wear Magic Rings and Backpacks

Curios API 9minecraft Mod adds extra inventory slots so you can wear rings, belts, amulets, and backpacks. It works behind the scenes to give other mods a place to put their special items. By itself, the mod does not add any new blocks or mobs to the game. You only need to install it when another mod asks for it. It gives you a new screen right next to your normal inventory where you can check all your equipped accessories.

## What this build is

An unofficial rebuild of **TheIllusiveC4**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
